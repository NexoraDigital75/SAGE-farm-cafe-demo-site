SAGE FARM CAFE — NEXORADIGITAL WEBSITE CONCEPT

FILES
- index.html: complete responsive static website (CSS and JavaScript included)
- images/: all local WebP images required by the page

RUN LOCALLY
1. Extract the ZIP.
2. Open index.html in a browser.
3. Keep the images folder next to index.html. Do not move individual images out of that folder.

PUBLISH WITH GITHUB PAGES
1. Extract this ZIP on your Mac.
2. Open your GitHub repository and choose Add file → Upload files.
3. Open the extracted SAGE-Farm-Cafe-NexoraDemo folder in Finder.
4. Drag index.html and the images folder into the GitHub upload area. If folder upload is unsupported, open images and upload all images inside it into a GitHub folder named images (create the folder by uploading a file with path images/filename.webp, or use GitHub's web upload interface that preserves folders). Keep exact filenames and folder structure. README.txt is optional for the website.
5. Commit the changes to the main branch.
6. Go to repository Settings → Pages. Choose Deploy from a branch, select main and /(root), then Save.
7. Wait for GitHub Pages to deploy. The expected URL format is https://YOUR-USERNAME.github.io/REPOSITORY-NAME/ . This is a format example, not a verified live URL.
